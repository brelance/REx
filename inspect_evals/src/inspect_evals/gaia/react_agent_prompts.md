# GAIA ReAct Agent Prompt Templates

This document records every GAIA-specific and Inspect ReAct text prompt used by `gaia.default_solver()`. Placeholders in braces are populated at runtime. Bash, Python, web-browser, and submit tool schemas and tool-result messages are supplied separately by Inspect and the model provider, so they are not static text prompts.

## Runtime Message Flow

```text
system instructions
GAIA sample input
assistant reasoning and tool calls
tool results
optional continue prompt when the assistant emits no tool call and has not submitted
optional incorrect-submission prompt when max_attempts is greater than one
submit(answer=...)
```

## Shared GAIA Sample Input

Source: `dataset.py::DEFAULT_INPUT_PROMPT`.

```text
Please answer the question below. You should:

- Return only your answer, which should be a number, or a short phrase with as few words as possible, or a comma separated list of numbers and/or strings.
- If the answer is a number, return only the number without any units unless specified otherwise.
- If the answer is a string, don't include articles, and don't use abbreviations (e.g. for states).
- If the answer is a comma separated list, apply the above rules to each element in the list.

{file}

Here is the question:

{question}
```

`{file}` is either empty or rendered as:

```text
The following file is referenced in the question below and you will likely need to use it in order to find the correct answer: /shared_files/{filename}
```

## System Instructions

Source: `gaia.py::DEFAULT_AGENT_INSTRUCTIONS`.

```text
You are an autonomous AI agent, consisting of a large language model and a scaffolding program that runs on a linux VM.

You have full control over your VM through the scaffolding program's provided functions, including: writing and editing files, running bash commands, installing packages etc.. From your VM, you can access the internet.

You are state-of-the-art, and excellent at analysis, planning and programming. You possess encyclopedic knowledge of the world. You write in a very direct and concise style.

You are resourceful and adaptive, and you never give up. Before deciding something can't be done, you try it out. You consider multiple options and choose the best one. If your current approach doesn't work, you formulate a new plan. You are given a task you need to solve completely on your own.

Please think step by step before calling tools. When you are ready to answer, use the submit tool to provide your final answer.
```

`default_solver()` constructs the prompt with:

```python
AgentPrompt(
    instructions=DEFAULT_AGENT_INSTRUCTIONS,
    assistant_prompt=None,
    submit_prompt=None,
)
```

Consequently, Inspect's generic `DEFAULT_ASSISTANT_PROMPT` and `DEFAULT_SUBMIT_PROMPT` are deliberately not appended. The default handoff prompt is also not appended because this solver has no handoff tools. The system message received by the model is therefore exactly the instructions above.

## Continue Prompt

Source: the installed Inspect version's `DEFAULT_CONTINUE_PROMPT`. ReAct inserts this as a user message when an assistant turn contains no tool call and no successful submission.

```text
Please proceed to the next step using your best judgement. If you believe you have completed the task, please call the `submit()` tool with your final answer.
```

## Incorrect-Submission Prompt

Source: the installed Inspect version's `AgentAttempts.incorrect_message`. This is only reachable when `max_attempts` is greater than one and a submitted answer scores as incorrect.

```text
Your submission was incorrect. Please proceed and attempt to find the correct answer.
```

With GAIA's default `max_attempts=1`, no retry follows the first submission, so this prompt is normally not sent.

## Tool Context

The ReAct model receives these tools:

```text
bash(timeout=180)
python(timeout=180)
web_browser()
submit(answer: string)
```

The default submit tool metadata is:

```text
name: submit
description: Submit an answer for evaluation.
required argument: answer (string), described as "Submitted answer"
```

`AgentSubmit(answer_only=True, keep_in_messages=True)` makes the submitted `answer` the sample output and retains the submit call in the transcript. These settings affect execution and output handling, not the text of the prompt.

The exact provider-facing JSON schemas for all tools are generated by the installed Inspect version and are not concatenated into the system or user prompt strings above.
